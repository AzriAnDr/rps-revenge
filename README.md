# Rich Presence Studio для Revenge Classic

Экспериментальная мобильная версия редактора карточек Discord. **На настоящем Android ещё не проверена:** совместимость с конкретной версией Discord, видимость другим пользователям и работа в фоне требуют проверки на телефоне.

## Установка

1. Установи [Revenge Manager из официальных релизов](https://github.com/revenge-mod/revenge-manager/releases/latest) и следуй его процедуре установки Discord с Revenge (без root). Менеджер сам показывает доступную совместимую версию Discord. Этот проект не поставляет перепакованный Discord APK.
2. В Revenge Classic открой настройки плагинов, нажми добавление и вставь ссылку:

   `https://azriandr.github.io/rps-revenge/dist/`

3. Включи Rich Presence Studio и открой его настройки. Создай профиль, сохрани и нажми «Применить». Для первого теста используй только текст, затем добавь картинку и кнопки.
4. Попроси другого пользователя посмотреть карточку. Сообщение об отправке означает вызов API клиента, а не подтверждение сервером Discord.

Целевая среда: Revenge **Classic** (Vendetta-compatible API), Android 15 пользователя. Revenge Next пока не поддерживается. Root не требуется. Реального устройства в среде разработки нет.

## Быстрый вход из профиля

Плагин добавляет кнопку **RPS** в нижнюю панель собственного профиля рядом с «Задания», «Магазин», «Настройки». Она открывает тот же редактор. Поддерживаются русские и английские названия панели. Это экспериментальная интеграция: она проверена на модельных деревьях React, но пока не на реальном Discord 350.8. Если структура панели отличается, кнопка не добавляется; редактор остаётся доступен через Revenge → Plugins → Rich Presence Studio → значок гаечного ключа.

После обновления плагина перезапусти Discord и заново открой профиль. Плагин не изменяет существующие действия панели.

## Возможности

- Сохранённые профили, название, подробности, состояние и тип активности.
- Большая/маленькая картинка по прямой публичной ссылке или Art Asset.
- Две кнопки с текстом, обычными emoji и URL; таймер с момента применения.
- Общий Application ID `1563133363232055448`, возможность указать собственный.
- Ручное применение, выключение, восстановление после запуска только для того же аккаунта.
- Совместимый с десктопным RPS импорт/экспорт JSON (`rich-presence-studio`, версия 1).

Музыки, локального музыкального сервера и загрузки картинок из галереи в этой версии нет. Для изображений вставляй готовую ссылку. Android может остановить Discord в фоне; постоянная активность при закрытом приложении не гарантируется. Не включай одновременно несколько плагинов Rich Presence.

## Автоматическая синхронизация по Wi-Fi

1. Обнови настольный RPS до сборки с вкладкой «Синхронизация» и перезапусти Discord.
2. На ПК открой эту вкладку, выбери адрес Wi-Fi или Ethernet своей домашней сети и включи синхронизацию. Нажми «Скопировать код для телефона».
3. На телефоне подключись к той же сети, войди в тот же аккаунт Discord, открой настройки RPS и вставь код в блок синхронизации. Нажми «Подключить».
4. Сохраняй профили как обычно. Телефон проверяет изменения каждые 10 секунд, ПК — каждые 5 секунд. Discord на ПК должен работать; на телефоне Android может приостанавливать приложение в фоне.

Синхронизируются сохранённые профили, включая удаления. Активная карточка, музыкальные настройки и несохранённый черновик не переключаются. При одновременном редактировании одного профиля сохраняется отдельная копия с пометкой «конфликт». После отсутствия сети изменения объединяются при следующем подключении. Максимум — 50 профилей; при превышении лимита обмен останавливается с ошибкой, локальные данные сохраняются.

Облака и отдельной регистрации нет. ПК слушает только выбранный локальный IPv4-адрес, порт TCP 38474. Содержимое обмена зашифровано AES-GCM-SIV (библиотека noble-ciphers). Код подключения — секрет доступа к профилям: передавай его только своему устройству. Кнопка «Отозвать старый код» на ПК отключает ранее выданные коды. При смене аккаунта требуется ручное подключение; при смене IP ПК скопируй новый код.

Если соединение не устанавливается, проверь статус в настройках RPS, адрес ПК, VPN и изоляцию клиентов гостевой Wi-Fi сети. Если Windows предложит сетевой доступ Discord, разреши его только для своей частной сети. Установщик не меняет правила брандмауэра автоматически. Работа сетевого обмена на настоящем Android ещё требует проверки, в том числе разрешение локального HTTP в конкретной сборке Discord/Revenge.

Ручной импорт/экспорт JSON остаётся доступным. GitHub Pages хранит только публичный код плагина, а не личные профили и коды подключения.

## Сборка и проверки

Node.js 22+: `npm ci`, `npm run build`, `npm test`. Два файла в `dist/` являются устанавливаемым плагином. В репозитории нет токенов Discord; используется API уже работающего клиента. Профили хранятся в локальном хранилище Revenge.

Автотесты проверяют модель, перенос данных, гонки загрузки изображений, очистку активности, смену аккаунта, переподключение и формат загрузчика. Они не заменяют тест на Android.

## Основа адаптера

- [Revenge Classic loader/API, 577c7f2](https://github.com/revenge-mod/revenge-bundle/tree/577c7f20fc040020fabeb871115b028c1d5d771e/src/core/vendetta).
- Мобильный `LOCAL_ACTIVITY_UPDATE` и предварительная инициализация `SET_ACTIVITY` проверены по [модулю Last.fm](https://github.com/kmmiio99o/vd-plugins/blob/20ed8ac703a43c45557115da504844621fe9c8fb/plugins/Last.fm/src/modules.ts).
- Логика профилей перенесена из собственного настольного Rich Presence Studio, GPL-3.0-or-later. Изменения для Hermes: генерация локальных UUID без обязательного Web Crypto, подсчёт UTF-8 без TextEncoder.

Лицензия: GPL-3.0-or-later. Проект не является официальным продуктом Discord, Vencord или Revenge.

Шифрование: vendored @noble/ciphers 2.4.0, MIT; лицензия в `src/shared/vendor/noble/LICENSE`.

## Обновление настольной версии 0.3.1

[Установщик Windows и исходники](https://github.com/AzriAnDr/rps-revenge/releases/tag/desktop-v0.3.1). В настольной версии 0.3.0 открой RichPresenceStudio → Обновления, проверь наличие обновления и нажми установку.

Если Catbox недоступен, загрузка картинки автоматически пробует img402. Редактор предупреждает: img402 хранит картинки до 1 МБ без срока в пределах времени работы сервиса, а более крупные — 30 дней после загрузки. Настройки и сторонние плагины сохраняются существующим механизмом установщика.
