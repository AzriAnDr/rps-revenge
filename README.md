# Rich Presence Studio для Revenge Classic

Экспериментальная мобильная версия редактора карточек Discord. **На настоящем Android ещё не проверена:** совместимость с конкретной версией Discord, видимость другим пользователям и работа в фоне требуют проверки на телефоне.

## Установка

1. Установи [Revenge Manager из официальных релизов](https://github.com/revenge-mod/revenge-manager/releases/latest) и следуй его процедуре установки Discord с Revenge (без root). Менеджер сам показывает доступную совместимую версию Discord. Этот проект не поставляет перепакованный Discord APK.
2. В Revenge Classic открой настройки плагинов, нажми добавление и вставь ссылку:

   `https://azriandr.github.io/rps-revenge/dist/`

3. Включи Rich Presence Studio и открой его настройки. Создай профиль, сохрани и нажми «Применить». Для первого теста используй только текст, затем добавь картинку и кнопки.
4. Попроси другого пользователя посмотреть карточку. Сообщение об отправке означает вызов API клиента, а не подтверждение сервером Discord.

Целевая среда: Revenge **Classic** (Vendetta-compatible API), Android 15 пользователя. Revenge Next пока не поддерживается. Root не требуется. Реального устройства в среде разработки нет.

## Возможности

- Сохранённые профили, название, подробности, состояние и тип активности.
- Большая/маленькая картинка по прямой публичной ссылке или Art Asset.
- Две кнопки с текстом, обычными emoji и URL; таймер с момента применения.
- Общий Application ID `1563133363232055448`, возможность указать собственный.
- Ручное применение, выключение, восстановление после запуска только для того же аккаунта.
- Совместимый с десктопным RPS импорт/экспорт JSON (`rich-presence-studio`, версия 1).

Музыки, локального музыкального сервера и загрузки картинок из галереи в этой версии нет. Для изображений вставляй готовую ссылку. Android может остановить Discord в фоне; постоянная активность при закрытом приложении не гарантируется. Не включай одновременно несколько плагинов Rich Presence.

## Перенос между телефоном и ПК

На ПК экспортируй профили RPS в JSON, открой файл как текст и вставь его в «JSON профилей» на телефоне → «Импортировать JSON». Обратно: «Копировать экспорт» на телефоне → сохрани текст в `.json` → импортируй в настольном редакторе. Импорт добавляет профили с новыми ID, существующие не заменяет. Несохранённые изменения редактора не экспортируются.

Это ручной перенос, **не автоматическая синхронизация**. Настройки публикации и текущий активный профиль не синхронизируются. Автосинхронизация возможна отдельной функцией через выбранное пользователем хранилище с авторизацией и разрешением конфликтов. GitHub Pages хранит код плагина, а не личные профили.

## Сборка и проверки

Node.js 22+: `npm ci`, `npm run build`, `npm test`. Два файла в `dist/` являются устанавливаемым плагином. В репозитории нет токенов Discord; используется API уже работающего клиента. Профили хранятся в локальном хранилище Revenge.

Автотесты проверяют модель, перенос данных, гонки загрузки изображений, очистку активности, смену аккаунта, переподключение и формат загрузчика. Они не заменяют тест на Android.
